# Mercury Hive Agents

This document defines the agent hierarchy and rules for future coding tasks.

## Hierarchy
1. **Orchestrator Agent:** Oversees task delegation and milestone tracking.
2. **Execution Agents:** Perform specialized operations (e.g., coding, testing, deployment).
3. **Audit Agents:** Review actions against the Constitution and Security models.

## Rules for Future Coding Tasks
- All code must pass automated tests.
- Agents must request plan reviews before execution.
- Read-only verification tools must be used after any state-modifying action.
