# Mercury Hive Roadmap

## Build 0: Foundation
- **Scope:** Blueprint freeze, repository structure setup, and documentation placeholders.
- **Out of Scope:** Any code implementation or running services.

## Build 1: Core Services
- **Scope:** Initialization of core backend APIs and minimal frontend skeleton.
- **Out of Scope:** Advanced agent interactions or complex UI.

## Build 2: Data Persistence
- **Scope:** Database setup and initial integration with backend services.
- **Out of Scope:** High-availability clustering or advanced caching.

## Build 3: Memory Model Integration
- **Scope:** Implementation of Centralized Memory Model for agent state tracking.
- **Out of Scope:** Distributed memory synchronization across multiple clusters.

## Build 4: Model Gateway Implementation
- **Scope:** Secure Gateway setup for interactions with external AI models.
- **Out of Scope:** Support for arbitrary, unvetted external APIs.

## Build 5: Agent Framework Skeleton
- **Scope:** Basic hierarchical agent structure based on AGENTS.md.
- **Out of Scope:** Autonomous multi-step decision making without human oversight.

## Build 6: Security and Permissions
- **Scope:** Enforcement of SECURITY_MODEL and PERMISSION_MODEL across the architecture.
- **Out of Scope:** Advanced heuristic-based anomaly detection.

## Build 7: UI/UX Refinement
- **Scope:** Development of comprehensive frontend for owner interaction and monitoring.
- **Out of Scope:** Mobile application deployment.

## Build 8: Task Lifecycle & Automation
- **Scope:** Full implementation of the TASK_LIFECYCLE, from request to verification.
- **Out of Scope:** Self-modifying code execution environments.

## Build 9: Final Polish & Release
- **Scope:** Performance tuning, security auditing, and final documentation alignment.
- **Out of Scope:** Post-release feature additions.
